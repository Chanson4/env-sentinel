# Contributing

Small, useful changes are welcome. Start with a real workflow and a synthetic example.

1. Open an issue for larger changes so the scope can be discussed.
2. Keep the runtime dependency-free. Do not add frameworks, bundles or network services.
3. Run `python -m unittest discover -s tests -v`.
4. Add a regression test when fixing a behavioral bug. Check desktop and mobile for UI changes.
5. Update English and Chinese usage docs when behavior changes.
6. Send a focused pull request describing the problem, the change and validation.

Do not include real configuration values, private JSON, credentials or personal data in issues, screenshots or fixtures. Be kind, precise and patient with contributors.

The roadmap in the README lists areas for improvement; it is not a delivery promise. Documentation clarifications and small accessibility improvements are good first contributions.
